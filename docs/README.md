# Documentation

LiveDiff keeps the current product and technical record intentionally small.

- [Product](PRODUCT.md) explains the problem, direction, constraints, and adjacent projects.
- [Decisions](DECISIONS.md) records durable choices and their consequences.
- [Research](RESEARCH.md) records evidence behind the active product and technical direction.
- [Architecture](../DESIGN.md) is the current system reference.
- [Usage and installation](../README.md) is the user-facing entry point.

Completed implementation plans, handoffs, and superseded specifications are preserved in Git history rather than maintained as current documentation.
